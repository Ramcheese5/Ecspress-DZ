# ⚡ Экспресс-ДЗ

Сайт с фотографиями ответов на домашние задания. Чистый HTML + CSS + JavaScript.

## Что умеет

- Меню (select) с 11 предметами: Алгебра, Геометрия, ВиС, Русский язык, Английский язык, Литература, Физика, Информатика, Биология, География, История.
- Кнопка **«Выбрать»**: на компьютере — справа от меню, на телефоне — снизу под меню.
- **Список фото подхватывается автоматически** — просто положите фото в папку предмета и обновите страницу. Никакие программы запускать не нужно.
- Фотографии показываются **по одной в ряд, по центру**, а **над каждой фотографией — дата из имени файла**.
- Сортировка: **чем новее дата — тем выше**, внутри одной даты **меньший номер — выше**.
- Клик по фото открывает полный просмотр: стрелки, свайпы на телефоне, клавиши ← → и Esc, кнопка «открыть оригинал».
- Если по предмету фото нет — написано «Пока нет ответов на задания».

## Как добавить фото

1. Положите фото в папку нужного предмета (например, `Алгебра/`).
2. Назовите файл по формуле **ДДММГГГГ + номер**:

| Имя файла | Расшифровка |
|---|---|
| `220920261.png` | 22 сентября 2026 года, фото №1 |
| `1210202612.jpg` | 12 октября 2026 года, фото №12 |

   - Дата — первые 8 цифр: день (2), месяц (2), год (4). Всё, что дальше — номер фото.
   - Годится: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.
3. Обновите страницу — фото уже на сайте, сверху, если дата свежая.

## Файлы сайта

```
index.html            — страница
style.css             — стили (адаптив: телефон + компьютер)
script.js             — логика (меню, сортировка, просмотр фото)
<папки предметов>/    — фото по предметам
```

Дополнительные файлы (не нужны при работе сайта на сервере):

```
manifest.js           — запасной список фото (если сайт открыт без сервера)
update_manifest.py / .bat / .sh — обновляют запасной список
```

## Как это работает

Сайт запрашивает список фотографий у сервера (`/api/photos`), который при каждом
запросе сам просматривает папки предметов. Поэтому новое фото появляется на
сайте сразу после обновления страницы — ничего запускать и настраивать не надо.

Если открыть папку сайта как обычные файлы (без сервера), сайт использует
запасной список `manifest.js` — тогда после добавления фото стоит один раз
запустить `update_manifest.bat` (Windows) или `update_manifest.sh` (Linux/Mac).

## Демо-фото

Сейчас в папках лежат картинки-примеры с пометкой «Пример — замените своим фото».
Просто удалите их и положите свои — по инструкции выше.
